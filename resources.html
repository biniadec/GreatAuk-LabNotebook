Genome Resources

Public databases you'll use throughout this project to find reference genomes and sequencing data. More resources — and project-specific links — will be added here as the course develops.

NCBI

The National Center for Biotechnology Information — the central U.S. hub for sequence databases, literature (PubMed), and genomic tools.

NCBI Datasets

A modern interface for browsing and downloading genome assemblies, annotations, and related metadata directly — the fastest way to find a candidate reference genome.

NCBI SRA

The Sequence Read Archive — the primary repository for raw high-throughput sequencing reads (FASTQ data) linked to published studies.

ENA

The European Nucleotide Archive — Europe's equivalent of the SRA/GenBank, often with more direct FTP/HTTPS download links for raw reads and assemblies.

More resources (e.g. species-specific databases, annotation tools, or project-specific data repositories) will be added to this page as the project progresses.
